# Pulse Analytics - Metrics Dictionary:

This document explains the numerical metrics displayed on the Home and Insights screens of the Pulse application in simple English.

| Metric | Example Value| Unit | Explanation |
| Pulse Score | 87 | Score | It displays the overall score on the Home screen to represent the user's wellness or progress |
| Progress Score | 87/100 | Score | It indicates the user's overall progress. A score out of 100 |
| Steps | 7,013 (Home), 8643 (Insights) | Steps | It caculates the total number of steps recorded of the user during the selected days |
| Sleep Duration | 8h 12m | Hours and minutes | It calculates the amount of time the user slept during the recorded sleep period |
| Calories | 990 (Home),2125 (Insights) | kcal | It calculates the calories recorded by the user during the selected days |
| Water Intake | 2.1 L | Litres | It displays the amount of water recorded by the user compared with the displayed daily goal of 3 litres |
| Heart Rate | 67 bpm | Beats per minute | It calculates the number of heartbeats per minute recorded by the user |
| Daily Streak | 12 (Home), 5 (Insights) | Days | It shows the number of consecutive days represented by the activity streak indicator |
| Steps Change | +12.5% | Percentage | It displays the displayed change in steps for the selected Insights period |
| Sleep Change | +32 (Insights), +43 (Home) | Minutes | It displays the displayed difference in sleep duration |
