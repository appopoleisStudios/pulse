# Health Demo Dataset

# Introduction:
This folder contains synthetic health data created for testing and demonstrating the Pulse application. All records in the csv file are random and no real personal or health information is included.

# Dataset:
- File: `demo_data.csv`
- Users: 2 fake demo users
- Duration: 14 days (1 October 2026 – 14 October 2026)
- Total records: 28

# Columns:
| Column | Description |
|---|---|
| user_id | Fake demo user identifier |
| date | Date in DD-MM-YYYY format |
| steps | Daily step count |
| sleep_hours | Total hours of sleep |
| calories | Daily calorie intake |
| protein_g | Daily protein intake in grams |
